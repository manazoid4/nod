## 4. LinkedIn: built in the open

Piblo is open source from day one.

The firmware, the Windows software and the website are on GitHub under the MIT licence. The device is an M5Stack Cardputer ADV. I did not make it and it is not made in Britain. The design and the software are mine.

It is early and mostly one person. If you want to test it or read the code, you are welcome.

Follow the build: https://piblo.co.uk
