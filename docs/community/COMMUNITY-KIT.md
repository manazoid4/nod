# Piblo community kit

Piblo is an early prototype: an M5Stack Cardputer ADV running our firmware, plus a PC app. It is not on sale and no price is set.

## Welcome message
```
Welcome to Piblo. I'm Maz, a solo dev in the UK building a pocket hold-to-talk device for your PC.
Piblo is a prototype, not on sale yet. No price is set.
Follow the build in #dev-updates, report problems in #bugs, vote on ideas in #feature-requests.
I'll say plainly what works and what doesn't. Be kind, no spam, no selling.
```

## Development-update format
```
Piblo update, <date>
Worked: <one measured thing, with a number>
Broken / not done: <one honest limit>
Next: <one thing for the coming week>
Clip/screenshot: <real only, or "none this week">
Question for you: <one specific ask>
```

## Feature voting
1. Post one request per thread: a title and the problem it solves.
2. React with a thumbs-up to vote. One vote per person, no voting for your own request.
3. Each Sunday the top three by votes get a reply: Planned, Maybe or Not now, with a reason.
4. Votes guide priority. They are not promises or delivery dates.

## How we measure interest
Links to piblo.co.uk may carry tags like `utm_source=...` so we can see which community a visit came from. This only tells us which post was useful. The launch list asks for an email (required) and an optional name, and you can ask to be removed at any time via info@piblo.co.uk.
