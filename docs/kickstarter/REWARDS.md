# Nod: reward tiers (draft structure)

Status: STRUCTURE ONLY. Every price and cost is `[TBD - needs supplier quote]`. Do not invent or round numbers. Fill from `ECONOMICS.csv` once real quotes exist. Check Kickstarter's current rules on hardware rewards before publishing; the project audit warns that rewards should not be simple resale of an off-the-shelf board.

Common rules for every tier:
- The description must say a Windows PC and Wi-Fi are required.
- Planned features (SUBTITLES, routine builder, larger screen) must not be promised as reward contents.
- Shipping and VAT must be stated or clearly handled.

Decide before filling this in:
1. Whether cases are printed in-house or by a service (changes yield, labour and lead time).
2. How many kits you can realistically print, assemble and test.
3. Which countries you will ship to, given battery transport rules.
4. Whether you are VAT registered.
