# v1.5 device test: what Maz does

Proves each v1.5 item on the real Cardputer ADV and MAZPC. A box is ticked in [NOD_STATUS.md](../NOD_STATUS.md) only after the step below passes on the device. Write the result and date next to each item.

**Before you start:** plug the Cardputer into USB-C charging and keep it on home Wi-Fi. Core must be running on MAZPC.

## 1. Home, version, charging, update
1. Power on. Home shows the big talk circle and a blue talk dot. **Pass if** both are there.
2. Open **Keys & Help**, go to **About**. **Pass if** it says `nod v1.5.0 on Cardputer ADV`.
3. Search for **Charging** (or type `charge`). **Pass if** the app opens and shows the charge state.
4. Home: if it says `Update: press U`, press **U**, confirm. **Pass if** it installs and reboots, then About shows `v1.5.0`. Note: the battery must be charging for this. Do not test at low battery unless you choose to (see risks).

## 2. Voice: measure before and after
1. Open **Call nod** (press **T**).
2. Ask a short question, for example "what is on my list". Start a phone stopwatch when you let go of SPACE. Stop it when the first word of the reply is spoken.
3. Repeat 5 times. Write the 5 times in the test ledger, plus "robotic / not robotic" for each.
4. **Before:** 4.4 s and robotic (ledger #4). **Pass if** the median is clearly lower and the voice sounds less robotic to you.

## 3. Notes survive a restart
1. Open **Notes**. Write `v15 restart test <today's time>`. Save it.
2. Switch the Cardputer off, wait 10 seconds, switch it on.
3. Open **Notes** again. **Pass if** the note is still there, word for word.

## 4. One PC action, approved on the device
1. Open **Control** (press **O**), then **Control Center**.
2. Choose one allow-listed PC action from the list. Pick one you are happy to run.
3. The device shows an approval prompt. Press **Y** (or Enter) to allow, or **N** (or Esc) to deny.
4. **Pass if** the action runs on MAZPC after you press Y, and does not run after N. Write what ran.

## 5. Core serves the right build
1. On MAZPC, check the Core log for a line like `fw report ... build=<sha>`. Note the sha.
2. On the Cardputer, press **U** (step 1.4) to install from Core.
3. **Pass if** the Core log then shows the new sha, and About on the device shows `v1.5.0`. Installing an old build is a fail: stop and write it down.

## Risks and choices for Maz
- Charge first. The battery block was removed on main, but flashing on low battery is still a risk to avoid for now.
- Item 4 needs a real allow-listed action. Pick the one you use least.
- Anything you want to change on MAZPC (tasks, restarts) is for Maz to do, not the agents.
