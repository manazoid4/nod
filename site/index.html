Why nod is different

Approval you can feel.

Five design choices. They describe how nod is built; the status section says what is proven so far.

  • 01

    A real key is a deliberate yes

    You approve with a physical key press, from wherever you are. No screen to find, no app to open.

  • 02

    It never auto-approves

    No answer in 60 seconds falls back to the normal terminal question. nod never approves for you.

  • 03

    Works with any agent

    Any agent that can run a command or send a web request can notify nod through an open contract. First hook: Claude Code.

  • 04

    Your network, no cloud account

    Requests travel over your own private network (Tailscale or Wi-Fi) to a hub on your PC. Free AI models work.

  • 05

    Open source, no subscription

    The code is public and there is no nod subscription. Some AI providers you choose may have their own costs.

Related, and different: Anthropic's open-source Claude Desktop Buddy is excellent, but it uses Bluetooth and works with the desktop app. nod is built for any agent and reaches you over your own private network. nod is independent and not affiliated with Anthropic.

How it works

Three steps. One key.

The device is small on purpose. Your computer does the heavy lifting; nod is not a standalone cloud computer.

  1. Step 1

    Your agent asks

    Your AI agent hits something that needs a yes. A hook or web request sends it to a small hub on your PC.

  2. Step 2

    nod buzzes

    The hub passes the request over your private network. The device shows what was asked.

  3. Step 3

    You press a key

    One key approves, one key stops. Say nothing for 60 seconds and you get the normal terminal question instead.

AI agent→Hub on your PC→nod in your pocket→Approve / Stop

A paired PC, a network and some setup are required. Hub and device are verified to talk over Wi-Fi; the full approval loop is not yet.

Who it's for

For people who already run agents.

Developers, makers and founders who let AI agents work on their PC and want to say yes or no without sitting at the screen.

If you don't run an AI agent on a computer today, nod is not for you yet.

Questions backers ask

Straight answers.

Is it safe?

nod never auto-approves. One key approves, one key stops, and no answer in 60 seconds falls back to the normal terminal question. Requests travel over your own private network (Tailscale or Wi-Fi) to a hub on your PC, with no cloud account. The approval loop has not had an independent security review yet; see the readiness page.

Does it work with my agent?

The first approval hook is for Claude Code. Any agent that can run a command or send a web request can notify nod through an open contract documented in the repo. Adapters for Codex, Gemini CLI and Cursor are documented from their docs but untested on the device.

Do I need a subscription?

No nod subscription and no cloud account are needed. Free AI models work: the hub switches between free providers automatically and falls back to a local model. Providers you choose to use may have their own costs.

Is it open source?

Yes. The code is public on GitHub under the MIT licence.

When can I get one?

Not announced yet. There is no price, ship date or campaign date. The first target is the M5Stack Cardputer ADV; custom hardware in a CNC metal case is planned for later. Follow the build to hear first.
